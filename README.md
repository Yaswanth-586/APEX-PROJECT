📒 DIGI-NOTES

A Digital Smart Notes App

🚀 About the Project

DIGI-NOTES is a digital smart notes app developed as part of my internship at ApexPlanet Software Pvt. Ltd..
The goal of this project is to create a clean, simple, and user-friendly notes application with a strong focus on UI/UX design.

This repository contains the deliverables for Task 2: Designing & Implementing UI/UX.

🎨 Features Implemented (Task 2)

✅ Designed 9 app screens in Figma.
✅ Converted wireframes into responsive Android layouts using XML & Material Design.
✅ Applied themes, colors, and typography for consistency.
✅ Added basic navigation between all pages.
✅ Focused on user-friendly design and easy flow.
